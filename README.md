Basic dungeon crawler typing game, clear all enemies in the room in order to move onto the next stage.
In order to defeat an enemy the player must type out a specific phrase before the timer runs out, list of phrases can be found in "phrases.txt".

"WASD" to move

'E' = enemy
'#' = wall
'P' = player
'^' = next room
